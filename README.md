# CET 四六级背单词

项目目标：为 CET-4 考生提供一个简单、高效、流畅的本地化背词体验；第一版先验证“每天愿意打开、能顺利完成、复习顺序有价值”这三个核心假设。

项目状态：已立项，初版核心 UI、4025 条可追溯 CET-4 词汇和「我的」账号预留已接入。

当前阶段：词库内容增强、每日分批学习与自适应学习 V1 已完成；真实手机设备仍需单独复测。

正式立项日期：2026-09-05

项目分类：Codex Project / 01_进行中的项目

项目路径：`D:\CodexProjects\01_进行中的项目\四六级单词`

目标用户：CET-4 考生，第一版主要服务项目发起人和同学。

最终交付物：可在手机和桌面浏览器使用的 CET-4 背词网站，包含首页、背词未揭晓、背词答案展开、今日完成和「我的」个人中心，并能保存本地学习进度。

## 项目边界

首版包含：

- CET-4 首页：目标分数、考试倒计时、今日复习数、今日新词数、开始背词入口；
- 学习顺序：到期复习优先，再进入今日新词；
- 单词卡：发音、认识程度选择、分级答案展开、收藏、撤销、下一个；
- 今日完成：完成反馈与返回首页；
- 「我的」：游客模式、邮箱验证码登录 Bottom Sheet、个人资产入口；
- 本地保存：刷新或中途退出后恢复当前学习位置；
- 浅色 / 深色跟随系统与 `prefers-reduced-motion` 适配。

账号已完成 Supabase Email OTP 与 Local First 同步架构；真实邮件、Supabase 项目和数据库迁移仍需由部署环境配置后验证。
