# 单词导入设计说明

## 目标

让用户通过 CSV、JSON 或逐行粘贴，把自定义单词加入当前浏览器的词库，并在当前学习批次结束后进入每日学习队列。

## 范围

- CSV：`word,meaning`，首行可选表头。
- JSON：数组对象，至少包含 `word` 和 `meaning` 字段；也接受字符串数组，此时释义为空并提示补充。
- 粘贴：每行 `word, meaning`。
- TXT / Markdown：每行 `word, meaning`。
- DOCX / XLSX：提取正文或首个工作表中的文字，按同样的行规则识别。
- 文本型 PDF：提取文字后按同样的行规则识别；扫描版 PDF 暂不支持 OCR。
- 导入前校验空单词、空释义和重复单词，并显示成功与跳过数量。
- 数据只写入浏览器 localStorage，不上传网络。
- 导入词在词库中单独显示，并排入当前 20 词学习批次完成后的下一批学习。

## 数据规则

- 单词统一转为小写并按单词去重；内置词库优先，重复导入词不覆盖内置词义。
- 导入词使用本地生成 ID、`CET-4` 标签和“用户导入”来源标记。
- 导入数据与学习进度分开保存，清除导入词不会清除已有学习记录。

## 交互

- 词库页增加“导入单词”按钮。
- 导入面板提供格式选择、文件选择、文本输入和提交按钮。
- 导入成功后关闭面板、刷新词库并提示结果；无效内容保留在面板中供修改。
- 不新增账号、云同步、后台接口或第三方依赖。

## 验收

- 三种格式都能导入有效词条。
- 空行、缺少字段和重复词会被跳过并给出计数。
- 刷新后导入词仍存在。
- 当前学习批次不被打断，下一批包含导入词。
- 桌面和 390px 手机视口无横向溢出，控制台无新增错误。
